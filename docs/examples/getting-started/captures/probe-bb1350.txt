declared = already pinned in this host's userland_options, and never re-probed. probed = the device 
answered, so this one is worth pinning. assumed = otto could not ask, so the value is only what otto
did before it asked anything -- and it is left out of the pin for that reason, because inside a JSON
payload a guess is indistinguishable from a measurement.

probe. This is the pin in force:
