# Project & lab configuration

Two files describe everything otto knows about your project: a
`.otto/settings.toml` at the repository root, and the host data it names —
usually one or more `lab.json` files. `otto init` scaffolds both, but every
command reads them, which is why they are documented here rather than under any
one command.

```{toctree}
settings
lab-config
host-options
os-profiles
host-sources
```
