# #649 Landing 1: One Project Vocabulary — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename "repo" / "SUT dir" to "project" / "project root" across otto's code, CLI, on-disk keys and docs. Replace `OTTO_SUT_DIRS` with `OTTOPATH`. Ship the behaviour changes the spec attaches to the rename: a repeated root collapses, a project with two roots is refused, old coverage metadata is refused, and hermetic environments strip `OTTOPATH`.

**Architecture:** A one-off, table-driven rename script in the scratch directory (never committed) does the mechanical part in two runs:
- `--stage collisions` (T1) clears the names that would otherwise collide.
- `--stage all` (T2) renames identifiers token by token, rewrites the strings that code reads as names, and moves `otto.config.repo` to `otto.config.project`.

Hand tasks then make the behaviour changes test-first (T3–T7) and rewrite the prose (T8–T9). T10 adds the guards that keep the old words out and measures the import cost. The branch lands as one squash, `feat(config)!:`.

**Tech Stack:**
- Python 3.10 venv for otto. The rename script runs on system `python3` 3.12, whose `tokenize` yields the names inside f-strings.
- pydantic-settings (`OttoEnvSettings`), Typer, pytest with xdist.
- ruff, ty, tach, ast-grep.
- The covapp SPA in `web/src/covapp` (TypeScript, vitest, `make web`).

**Spec:** `docs/superpowers/specs/2026-10-17-649-project-vocabulary-design.md` (approved 2026-10-17, commit 5c267557b). This plan implements its landing 1 (§3) only. Every line number below is from the tree at af010a79c / 5c267557b.

**The rename script:** `/tmp/claude-1000/649-plan/rename.py`. It runs as `python3 /tmp/claude-1000/649-plan/rename.py ROOT --stage collisions|all|residual [--write] [--report DIR] [--manifest FILE]`.
- **It fails safe.** Each run computes everything in memory first: pass 1 (identifiers), pass 2 (strings code reads as names), the exact-text edits (`LINE_EDITS`, `POST_EDITS`, `REGEX_POST`) and the planned moves. It then validates the whole would-be tree: every changed Python file compiles and merges no two symbols of one scope or class (the collision check), each exact-text edit matches exactly once (an edit whose old text and new text are both absent is `ABSENT`, a refusal; the four edits that a rename pass changes again after they apply are recognised only structurally: exactly one statement (or anchored dict entry) of the named top-level function has the accepted post-state AST, reported `RENAMED-AFTER`, never by absence or by text; old and post state both present is a `CONFLICT` refusal, and a same-named def elsewhere in the file is `SHADOWED`), each move's destination is free. Only a clean validation is written, and only then are the modules moved (`git mv`). A refusal writes nothing, lists its reasons in `refusals.txt` and exits 1.
- Without `--write` it is a dry run that writes the same reports.
- `files_changed` counts every file whose content would change, whatever pass changes it, and `files_changed.txt` lists them.
- **Idempotence is proved by content, not by counters.** `--manifest FILE` writes the sha256 of every tracked file after the run. A second `--write` run of the same stage must print `files_changed=0 moves=0 name_edits=0 string_edits=0 exact_edits=0`, and its manifest must be byte-identical to the first run's (`cmp`).
- It never edits a negative inventory (`NEGATIVE_INVENTORIES`): the files that spell old names on purpose, including `tests/unit/test_vocabulary_renames.py`, which T2 writes before the sweep.
- `--stage residual` writes `residual_files.txt` (whole-word old words per file) and `residual_identifiers.txt` (every surviving spelling of a renamed identifier, with its line), which T8–T10 work from.
- Appendix A is its table, generated from the script itself (`/tmp/claude-1000/649-plan/appendix.py`), so the two cannot disagree.
- If the scratch directory is lost, the script is the one artifact to restore before T1 or T2. It is never committed, and it is not needed after T2.

## Decisions the spec left open

Each is decided here, with its reason, so no implementer re-decides it. Tasks cite them as D1–D24.

- **D1 The duplicate error.**
  - `DuplicateProjectError(BootstrapError)` lives in `otto/config/scope.py` beside its siblings (`DependencyError`, `ProjectScopeError`). It is not exported from any public namespace, so the golden diff stays exactly §4.1 (plus D19).
  - One error is recorded per root, so each rides the existing per-root containment path. Its attributes are `.root`, `.name` (the normalized name that matched), `.roots` and `.source == "OTTOPATH"`.
  - Each is framed with its own root, as spec §5.3 requires and as `BootstrapError` and `DependencyError` are: `project root <root>: project 'x' has N roots in OTTOPATH: a, b; keep one`. Every root's error names the project and every root that claimed it. The frame says "project root" from the start: the class is new, and T8 brings its siblings' `repo <root>:` frames to the same words.
- **D2 How `-I`/`-E` learn refused names.**
  - Public `select_projects(projects, include, exclude)` keeps its signature (golden unchanged).
  - A module-level, non-exported `select_projects_with_refused(…, refused)` and `refused_names(errors)` in `session/projects.py` are called by the two real callers, `cli/invoke.py:971` and `run_context.py:1452`.
  - The refused errors own no loaded project, so `classify_load_errors` already makes them fatal.
- **D3 The `CoverageInputError` home.**
  - The existing class in `coverage/errors.py`, with `field="cov_dirs"`; it already documents `cov_dirs` as a field for `run_coverage_report`.
  - Every present metadata file is validated. A missing file is still tolerated (Review Focus 4).
  - An old key, or a missing current key, is refused. The message names the directory and the key, and says to re-collect.
- **D4 The one shared sanitizer constant.**
  - `otto.config.env` gains `OTTO_ENV_PREFIX` and `is_otto_env_var(name)`, beside `OTTOPATH_ENV_VAR`; in-process code and tests call it.

Why the spine is serial:
- T1 must land before the sweep (§4.2).
- T2 rewrites roughly 480 files, so nothing can run beside it.
- T3 edits every file that names the environment variable, which cuts across all of wave A's files.

Why T10 is last: the guard fails while any prose old word remains, and the import-budget measurement needs T4's collapse in place.

Why T8 is serial (Astra's plan check): its splits cannot be made independently green. Run in parallel from one base, a split either leaves another package's pins red or edits a file another split also edits. Run serially, each split starts from the previous split's commit, owns every pin of the strings it changes wherever that pin lives, and is green on its own tip. The splits keep their file lists (Task 8) so each commit stays reviewable.

Why T9 stays parallel: it edits only `docs/`, `README.md`, `AGENTS.md`, `todo/` and the `REJECTION_INVENTORY` entry for `docs/configuration/settings.md` in `tests/_fixtures/vocabulary.py`, none of which a T8 split touches, and it runs no pytest and no docs build.
```python
def kept_path_spelling(entry: str) -> str:
    """The spelling otto keeps for a root it was given: ``~`` expanded, a relative entry joined to the cwd.

    Nothing else changes: ``..`` and symlinks stay exactly as written.
    ``os.path.abspath`` would fold ``<link>/..`` lexically, naming a different
    directory than the filesystem does. The stdlib-only console-script shim
    mirrors this function byte for byte (``otto._shim_complete``).
    """
    path = os.path.expanduser(entry)
    return path if os.path.isabs(path) else os.path.join(os.getcwd(), path)


@functools.lru_cache(maxsize=None)
def root_key(path: str) -> str:
    """The comparison key of a root in its kept spelling: its ``os.path.realpath``.

    Used only to detect a repeated root and to key the workspace home, never to
    load or to hand to a child. Cached, so each root is resolved once per
    process however many times the env settings are built (``realpath`` costs
    one ``lstat`` per path component); ``otto.bootstrap.invalidate`` clears it
    with the rest of the cached composition state.
    """
    return os.path.realpath(path)


def collapse_path_list(entries: list[str]) -> list[str]:
    """Drop every entry naming the same directory as an earlier one; the first keeps its spelling.

    Two entries are the same when their :func:`root_key` agree. That key is
    only compared, never kept or passed on. A list of fewer than two entries is
    returned as is, so the common one-root workspace resolves nothing here.
    """
    if len(entries) < 2:
        return list(entries)
    seen: set[str] = set()
    kept: list[str] = []
    for entry in entries:
        key = root_key(entry)
        if key not in seen:
            seen.add(key)
            kept.append(entry)
    return kept


def ottopath_entries(value: str) -> list[str]:
    """The roots an ``OTTOPATH`` value names: split, kept spelling, repeats collapsed."""
    return collapse_path_list([kept_path_spelling(e) for e in _PATH_LIST_SEP.split(value) if e])
```

```python
class DuplicateProjectError(BootstrapError):
    """Two or more ``OTTOPATH`` roots hold one project, so none of them loads.

    One is recorded for EACH root that claimed the name, so each is contained
    like any other per-root load failure: otto never guesses which copy is
    meant. Each is framed with its own root, as its siblings are, and names
    the project and every root that claimed it. *name* is the normalized name
    the roots share.
    """

    def __init__(self, root: Any, name: str, roots: "list[Path]") -> None:
        """Frame ``project root <root>: project <name> has N roots in OTTOPATH: …; keep one``."""
        listed = ", ".join(str(r) for r in roots)
        Exception.__init__(
            self,
            f"project root {root}: project {name!r} has {len(roots)} roots in OTTOPATH: {listed}; keep one",
        )
        self.root = root
        self.name = name
        self.roots = list(roots)
        self.source = "OTTOPATH"
```

```python
Run as a module to list the old words left in some files, allowed lines aside::

import re
import sys
from pathlib import Path

OLD_WORD = re.compile(r"\b(?:repo|repos|Repo|sut_dir|sut_dirs)\b")
"""Whole-word, so ``repository``, ``repo1`` and ``NotAGitRepoError`` never match."""

GIT_SENSE: dict[str, list[str]] = {
    # path -> exact fragments of lines that use "repo" in git's sense. A line
    # containing one is allowed. Each fragment must still occur, so a stale
    # entry fails too.
}

REJECTION_INVENTORY: dict[str, list[str]] = {
    # path -> the exact lines (compared stripped, whole line) that must spell an
    # old word in order to refuse it, or to tell a reader it was removed. Each
    # must occur exactly once in its file.
    # Coverage metadata an older otto wrote is refused by its old keys (spec §5.5).
    "src/otto/coverage/reporter.py": ['_OLD_META_KEYS = ["repo_name", "sut_dir"]'],
}


def rejection_exempt(rel: str, line: str) -> bool:
    """True when *line* of *rel* is, whole and stripped, one of its rejection lines."""
    return line.strip() in REJECTION_INVENTORY.get(rel, [])


def allowed(rel: str, line: str) -> bool:
    """True when *line* of *rel* may keep an old word: a rejection line or a git-sense line."""
    return rejection_exempt(rel, line) or any(f in line for f in GIT_SENSE.get(rel, []))


def old_words(root: Path, rel: str) -> list[str]:
    """``path:line: text`` for each line of *rel* that spells an old word, allowed lines aside."""
    text = (root / rel).read_text(encoding="utf-8")
    return [
        f"{rel}:{n}: {line.strip()}"
        for n, line in enumerate(text.splitlines(), 1)
        if OLD_WORD.search(line) and not allowed(rel, line)
    ]


def main(argv: list[str]) -> int:
    """Print every old word left in the files named in *argv*; exit 1 if any."""
    found = [hit for rel in argv for hit in old_words(Path.cwd(), rel)]
    if found:
        sys.stdout.write("\n".join(found) + "\n")
    return 1 if found else 0


if __name__ == "__main__":
```

```python
"""The old project words cannot come back.

Spec ``docs/superpowers/specs/2026-10-17-649-project-vocabulary-design.md``
(Guards). ``OTTO_SUT_DIRS`` is refused in every tracked file. ``sut_dir`` /

match is whole-word, so ``repository``, ``repo1`` and ``NotAGitRepoError`` never
fire it. Every exemption is by path (below), by an exact line fragment
(``GIT_SENSE``) or by an exact whole line (``REJECTION_INVENTORY``); the two
tables live in ``tests/_fixtures/vocabulary.py``, shared with the prose check
and the rename script's residual inventory, and each entry says why.
"""

import re
import subprocess
from pathlib import Path

import pytest

from tests._fixtures.paths import PROJECT_ROOT
from tests._fixtures.vocabulary import GIT_SENSE, OLD_WORD, REJECTION_INVENTORY, allowed

OLD_VARIABLE = re.compile(r"\bOTTO_SUT_DIRS\b")
WORD_SCOPE = ("src/", "docs/")

EXEMPT_PREFIXES = [
    "docs/superpowers/",  # historical specs and plans keep the words of their day
    "CHANGELOG.md",  # generated from commit subjects; existing entries are history
    "tests/unit/test_moved_name_spellings.py",  # negative inventory: spells gone modules
    "tests/unit/test_vocabulary_renames.py",  # negative inventory: spells the old names
    "tests/unit/config/test_ottopath_env.py",  # pins that OTTO_SUT_DIRS does nothing
    "tests/unit/test_vocabulary_guard.py",  # this guard
]
CITED_SPEC = "2026-10-06-repo-and-scope-inputs-design"
"""A spec's file name that docstrings and docs cite; a citation is history."""


def _exempt(rel: str) -> bool:
    return any(rel == p or rel.startswith(p) for p in EXEMPT_PREFIXES)


def offences(root: Path, files: list[str]) -> list[str]:
    """``path:line: word`` for every old word in *files* (paths relative to *root*)."""
    found = []
    for rel in files:
        if _exempt(rel):
            continue
        try:
            text = (root / rel).read_text(encoding="utf-8")
        except (UnicodeDecodeError, IsADirectoryError, FileNotFoundError):
            continue
        in_scope = rel.startswith(WORD_SCOPE)
        for lineno, line in enumerate(text.splitlines(), 1):
            found.extend(f"{rel}:{lineno}: {m.group(0)}" for m in OLD_VARIABLE.finditer(line))
            if not in_scope or allowed(rel, line):
                continue
            words = OLD_WORD.finditer(line.replace(CITED_SPEC, ""))
            found.extend(f"{rel}:{lineno}: {m.group(0)}" for m in words)
    return found


def stale_exemptions(root: Path) -> list[str]:
    """Each git-sense fragment no longer found, and each rejection line not found exactly once."""
    stale = [
        f"{rel}: {fragment!r}"
        for rel, fragments in GIT_SENSE.items()
        for fragment in fragments
        if fragment not in (root / rel).read_text(encoding="utf-8")
    ]
    for rel, lines in REJECTION_INVENTORY.items():
        present = [line.strip() for line in (root / rel).read_text(encoding="utf-8").splitlines()]
        stale += [
            f"{rel}: {line!r} x{present.count(line)}" for line in lines if present.count(line) != 1
        ]
    return stale


def _tracked() -> list[str]:
    out = subprocess.run(
        ["git", "ls-files", "-z"],
        cwd=PROJECT_ROOT,
        capture_output=True,
        text=True,
        check=True,
    ).stdout
    return [p for p in out.split("\0") if p]

    found = offences(PROJECT_ROOT, _tracked())
    assert found == [], "\n".join(found)


def test_every_exemption_still_matches_exactly():
    assert stale_exemptions(PROJECT_ROOT) == []

REPORTER = "src/otto/coverage/reporter.py"


def _plant(root: Path, rel: str, body: str) -> None:
    (root / rel).parent.mkdir(parents=True, exist_ok=True)
    (root / rel).write_text(body)

    ("body", "expected"),
    [
        (f"{REJECTION_LINE}\n", []),
        (f"    {REJECTION_LINE}  \n", []),
        (f'{REJECTION_LINE}\nroot = meta["sut_dir"]\n', [f"{REPORTER}:2: sut_dir"]),

            f'{REJECTION_LINE}; root = meta["sut_dir"]\n',
            [f"{REPORTER}:1: sut_dir", f"{REPORTER}:1: sut_dir"],
        ),
        (f"# {REJECTION_LINE}\n", [f"{REPORTER}:1: sut_dir"]),
        (
            f"{REJECTION_LINE}  # the repo\n",
            [f"{REPORTER}:1: sut_dir", f"{REPORTER}:1: repo"],
        ),
    ],
    ids=[
        "exact",
        "indented",
        "next-line",
        "same-line-trailing",
        "commented-out",
        "trailing-comment",
    ],
)
def test_the_rejection_inventory_exempts_its_whole_line_and_nothing_else(tmp_path, body, expected):
    _plant(tmp_path, REPORTER, body)
    assert offences(tmp_path, [REPORTER]) == expected


@pytest.mark.parametrize(("copies", "count"), [(0, 0), (2, 2)], ids=["missing", "duplicated"])
def test_a_rejection_line_must_occur_exactly_once(tmp_path, copies, count):
    _seed_every_exemption(tmp_path)
    assert stale_exemptions(tmp_path) == []
    _plant(tmp_path, REPORTER, f"{REJECTION_LINE}\n" * copies + "x = 1\n")
    assert stale_exemptions(tmp_path) == [f"{REPORTER}: {REJECTION_LINE!r} x{count}"]


def _seed_every_exemption(root: Path) -> None:
    """Write every file the two tables name, each exemption present exactly once.

    Generated from the tables themselves, so an entry added later (a docs
    page's rejection lines, a git-sense fragment) is seeded too.
    """
    bodies: dict[str, list[str]] = {}
    for table in (REJECTION_INVENTORY, GIT_SENSE):
        for rel, entries in table.items():
            bodies.setdefault(rel, []).extend(entries)
    for rel, entries in bodies.items():
        _plant(root, rel, "".join(f"{entry}\n" for entry in entries))


def test_a_planted_old_word_turns_the_guard_red(tmp_path):
    _plant(tmp_path, "src/otto/x.py", '"""Load the repo."""\nsut_dir = 1\n')

        "src/otto/x.py:1: repo",
        "src/otto/x.py:2: sut_dir",
```
