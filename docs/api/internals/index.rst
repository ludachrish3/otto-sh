Internals
=========

These pages document otto's own modules, for contributors and for the links
the guides use to explain behaviour. Nothing here is public: an internal
module may change, move or disappear in any release, without a mark. A public
name is documented once, under :doc:`Public API <../index>`, and is left out
of these pages.
